# Проект: Космический Мусор. Backend( Обработка данных спутников (TLE))

## Описание

Эта часть проекта предназначена для обработки данных о спутниках, используя TLE (Two-Line Element) форматы. Она извлекает данные о действующих спутниках и мусоре из CelesTrak, вычисляет их координаты и скорости, а также парсит данные из конфигурационного файла `frontend_output.json`.

## Требования

- Python 3.6 или выше
- Библиотеки:
  - `requests`
  - `sgp4`
  - `astropy`

## Использование

Запустите основной скрипт main.py, указав путь к конфигурационному файлу frontend_output.json:

```bash

## Структура проекта:
```bash
.

├── parser.py

###
Классы и методы

main.py
    Функция run(config_path):
    Читает конфигурацию из frontend_output.json.
    Извлекает данные о спутниках и мусоре.
    Обрабатывает данные и сохраняет их в data.json.

parser.py
    Класс Satellite:

        Представляет спутник и вычисляет его координаты и скорость.
    Класс TLEFetch:

        Извлекает TLE данные из заданного URL.
    Класс SatelliteProcess:

        Обрабатывает данные о спутниках и мусоре, сохраняет их в JSON формате.
    Класс Parser:

        Парсит данные из frontend_output.json и объединяет их с существующими данными.

## Обработка ошибок
В проекте реализована обработка ошибок для следующих случаев:

Ошибки при декодировании JSON.
Ошибки при отсутствии файла.
Общие ошибки, возникающие во время выполнения.
